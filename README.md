# Source Toolkit

Android utility for Garry's Mod / Source Engine assets. Minimum Android version: 8.0 (API 26).

## Build
The GitHub Actions workflow builds a debug APK using JDK 17, Gradle 8.7, Android SDK 35 and Build Tools 35.0.0.

After pushing the complete Android Studio project, open **Actions → Android APK**. Download `SourceToolkit-debug-apk` from a successful run's Artifacts section.

The APK is a debug build for testing, not a Play Store release-signed package.
